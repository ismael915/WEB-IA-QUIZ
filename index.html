Resumo dos temas

Criar um site envolve estruturar informações, cuidar da apresentação visual e programar interações. A inteligência artificial pode apoiar esse trabalho, mas decisões e verificações continuam sendo responsabilidade de quem desenvolve.

  • HTML, CSS e JavaScriptHTML organiza o conteúdo com títulos, parágrafos e links. CSS define cores, tipografia, espaçamento e adaptação a diferentes telas. JavaScript dá comportamento à página, respondendo a ações e atualizando informações.
  • Inteligência artificial e promptsIA generativa pode ajudar a explorar ideias, redigir textos e criar rascunhos de código. Um bom prompt informa objetivo, contexto, público e formato esperado para orientar melhor a resposta.
  • Benefícios, limites e cuidadosA IA pode acelerar tarefas, mas também pode errar, inventar fontes ou sugerir código inseguro. Revise e teste as respostas, confirme informações e evite compartilhar dados pessoais ou confidenciais.
  • Etapas de criação de um siteDefina objetivo e público, planeje conteúdo, construa a estrutura e implemente o visual e as interações. Depois teste navegação e responsividade, corrija problemas e publique; melhorias fazem parte do processo.

    Configurar ranking compartilhado

    O ranking só é compartilhado depois de conectar um projeto Supabase. A criação do banco é manual para manter a chave administrativa protegida.

    1. Crie um projeto em supabase.com.
    2. No painel do projeto, abra o SQL Editor e execute o script abaixo.
    3. Em Project Settings > API, copie a Project URL e a chave pública anon ou publishable.
    4. No final deste HTML, substitua https://SEU-PROJETO.supabase.co e SUA_CHAVE_ANON_PUBLICA pelos valores do seu projeto; publique o arquivo atualizado.

    Não coloque a chave service_role neste arquivo. Como os resultados são enviados pelo navegador, o ranking é adequado para atividades de turma, mas não impede fraude deliberada.

    SQL de configuração
    create table if not exists public.quiz_scores (
  id uuid primary key default gen_random_uuid(),
  team_name text not null check (char_length(btrim(team_name)) between 1 and 32),
  score smallint not null check (score between 0 and 30),
  elapsed_seconds integer not null check (elapsed_seconds between 0 and 86400),
  created_at timestamptz not null default now()
);

alter table public.quiz_scores enable row level security;

grant select, insert on public.quiz_scores to anon, authenticated;

drop policy if exists "Anyone can read quiz scores" on public.quiz_scores;
create policy "Anyone can read quiz scores"
  on public.quiz_scores
  for select
  to anon, authenticated
  using (true);

drop policy if exists "Anyone can submit quiz scores" on public.quiz_scores;
create policy "Anyone can submit quiz scores"
  on public.quiz_scores
  for insert
  to anon, authenticated
  with check (
    char_length(btrim(team_name)) between 1 and 32
    and score between 0 and 30
    and elapsed_seconds between 0 and 86400
  );
